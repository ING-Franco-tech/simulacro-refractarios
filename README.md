# Simulacro · Materiales Refractarios (capítulo III)

Simulacro interactivo del parcial de Materiales Refractarios (UIS), resuelto paso a paso.

- **Punto 1 · Teoría:** 18 frases de las diapositivas para completar, con retroalimentación y explicación.
- **Punto 2 · Diagrama ternario CaO–Al₂O₃–SiO₂:** ubicar el refractario y la escoria, trazar la línea, identificar los triángulos de composición, la temperatura mínima de formación de líquido, el % de CaO que disuelve la mullita y la regla de la palanca (binaria y ternaria).
- **Punto 3 · Caso de ingeniería:** corrosión de un ladrillo de arcilla refractaria por una escoria básica: grado de silicato, normalización, diagrama ternario y recomendación de refractario.
- **Repaso** y **Resultados** (nota estimada sobre 5,0).
